# Changelog

All notable changes to EKE Open Review are documented in this file.

The project follows explicit versioning and traceable change control.
Architectural status does not imply implementation, verification,
certification, or production readiness.

## [Unreleased]

### Added
- Formalized the EKE Open Review evidence and review lifecycle architecture.
- Added independent verification contract and schema definitions.
- Added BABT certificate reference structure and validation fixtures.
- Added executable schema and contract validation tests.

### Verification
- Current repository verification results are limited to the tests
  actually executed against the implemented components.

## [0.1.0]

### Added
- Review Applications baseline.
- Active Reviews baseline.
- Completed Reviews baseline.
- Review Certificate baseline.
- Review Registry baseline.
- Disputes and Appeals baseline.
- Audit Log baseline.
- Independent Verification baseline.

### Notes
- These components are architectural baselines unless explicitly
  identified as implemented and tested.
- No certificate, registry entry, attestation, or review record
  constitutes independent certification merely by existing.
